============================================
STEP 1: MEMAHAMI NODE ARCHITECTURE
============================================

Di Godot, semua game object adalah "Node". Node bisa punya child nodes.
Struktur ini biasa disebut "Node Tree" atau "Scene Tree".

CONTOH STRUKTUR SNAKE GAME:
┌─────────────────────────────────┐
│ Game (Node2D) - ROOT NODE       │
├─────────────────────────────────┤
│ ├─ GameBoard (ColorRect)        │  <- Background game area
│ ├─ ScoreLabel (Label)           │  <- Text "Score: 0"
│ ├─ Snake (Node2D)               │  <- Ular (akan kita buat nanti)
│ └─ Food (Node2D)                │  <- Makanan (akan kita buat nanti)
└─────────────────────────────────┘

Parent-Child Relationship:
- Parent: Node yang lebih atas (Game)
- Child: Node yang ada di bawahnya (GameBoard, ScoreLabel, dll)

KENAPA PENTING?
- Jika parent di-move, child juga ikut bergerak
- Hierarchical organization = mudah dikelola
- Setiap node punya properties masing-masing

📝 PENJELASAN KONSEP:

Untuk membuat ular bergerak, kita butuh:
1. VARIABLE: snake_pos (posisi ular)
2. VARIABLE: direction (arah yang bergerak)
3. FUNCTION: _process() - dipanggil setiap frame
4. INPUT HANDLING: Input.is_action_pressed() - tangkap tombol keyboard

TIMING:
Ular tidak bergerak setiap frame (terlalu cepat!).
Ular bergerak setiap X detik pakai "move_timer".
Contoh: bergerak setiap 0.15 detik = smooth movement.

GRID SYSTEM:
Permainan snake itu grid-based (seperti catur).
- Tiap cell: 32x32 pixel
- snake_pos: posisi dalam grid (0-19, 0-14 untuk board 640x480)
- visual_pos: snake_pos * 32 = pixel position

STEP 2: TULIS KODE - SETUP VARIABLES
============================================

Sekarang kita tulis kode untuk movement.

Di script editor, hapus template default dan copy code ini:

---COPY MULAI---

extends Node2D

# ==========================================
# GAME CONSTANTS
# ==========================================
var GRID_SIZE = 32          # Ukuran tiap cell dalam pixel
var GRID_WIDTH = 20         # Jumlah cell horizontal (640 / 32 = 20)
var GRID_HEIGHT = 15        # Jumlah cell vertikal (480 / 32 = 15)
var MOVE_SPEED = 0.15       # Detik antara tiap movement

# ==========================================
# SNAKE VARIABLES
# ==========================================
var snake_pos = Vector2(10, 10)      # Posisi ular di grid (mulai tengah)
var direction = Vector2(1, 0)        # Arah sekarang (bergerak kanan)
var next_direction = Vector2(1, 0)   # Input untuk frame depan
var move_timer = 0.0                 # Counter untuk timing

# ==========================================
# MAIN FUNCTIONS
# ==========================================

func _ready():
    """
    _ready() dipanggil saat scene start
    Kita gunakan untuk setup awal game
    """
    pass  # Untuk sekarang, tidak ada setup khusus

func _process(delta):
    """
    _process() dipanggil setiap frame (~60 fps)
    delta = waktu (detik) sejak frame terakhir
    
    Kita gunakan untuk:
    1. Tangkap input keyboard
    2. Update timer movement
    3. Jalankan movement jika timer cukup
    """
    
    # ===== HANDLE INPUT (SETIAP FRAME) =====
    # Cek tombol keyboard dan update next_direction
    
    if Input.is_action_pressed("ui_right"):
        # Jika tombol kanan ditekan, dan ular tidak sedang bergerak kiri
        # (prevent reverse 180° - akan explain nanti)
        if direction != Vector2(-1, 0):
            next_direction = Vector2(1, 0)
    
    elif Input.is_action_pressed("ui_left"):
        if direction != Vector2(1, 0):
            next_direction = Vector2(-1, 0)
    
    elif Input.is_action_pressed("ui_down"):
        if direction != Vector2(0, -1):
            next_direction = Vector2(0, 1)
    
    elif Input.is_action_pressed("ui_up"):
        if direction != Vector2(0, 1):
            next_direction = Vector2(0, -1)
    
    # ===== UPDATE TIMER =====
    # Tambahkan delta ke timer setiap frame
    move_timer += delta
    
    # ===== MOVE SNAKE SETIAP X DETIK =====
    # Jika timer sudah >= MOVE_SPEED, ular bergerak
    if move_timer >= MOVE_SPEED:
        move_snake()           # Jalankan movement
        move_timer = 0.0       # Reset timer
        queue_redraw()         # Redraw canvas (akan explain di draw)

# ===== MOVEMENT FUNCTION =====

func move_snake():
    """
    move_snake() menggerakkan ular sesuai arah
    Dipanggil setiap MOVE_SPEED detik
    """
    # Update arah dengan input terbaru
    direction = next_direction
    
    # Pindahkan ular ke cell sebelah sesuai direction
    # direction adalah Vector2(1,0) / (-1,0) / (0,1) / (0,-1)
    # Jadi snake_pos berubah 1 cell per gerak
    snake_pos += direction
    
    # TODO: Nanti kita akan tambah:
    # - Cek collision (nabrak dinding, nabrak badan)
    # - Cek makan (collision dengan makanan)
    # - Draw body segments (ekor ular)

# ===== DRAW FUNCTION =====

func _draw():
    """
    _draw() dipanggil setiap frame untuk menggambar
    Ini tempat kita render snake, makanan, dll
    """
    # Gambar ular sebagai kotak merah di posisi snake_pos
    # Konversi dari grid position ke pixel position
    var head_screen_pos = snake_pos * GRID_SIZE
    var head_rect = Rect2(head_screen_pos, Vector2(GRID_SIZE, GRID_SIZE))
    
    # draw_rect(area, color)
    draw_rect(head_rect, Color.RED)

---COPY SELESAI---

Penjelasan:

1. VARIABLES:
   - GRID_SIZE = 32: tiap cell 32x32 pixel
   - snake_pos: posisi ular di grid (bukan pixel)
   - direction: arah sekarang (Vector2 dengan nilai -1, 0, atau 1)
   - next_direction: input dari pemain untuk frame depan
   - move_timer: counter untuk timing

2. _process(delta):
   - Jalankan setiap frame (~60 fps)
   - delta = waktu sejak frame terakhir
   - Kita gunakan untuk input handling dan timer
   - Setiap MOVE_SPEED detik, panggil move_snake()

3. move_snake():
   - Jalankan saat timer cukup
   - Update direction dengan next_direction
   - snake_pos += direction (gerak 1 cell)

4. _draw():
   - Gambar snake sebagai kotak merah
   - snake_pos * GRID_SIZE = konversi ke pixel

📝 PENJELASAN KONSEP:

ARRAY:
Array adalah variabel yang bisa menyimpan banyak nilai.
Contoh: var body_segments = [Vector2(10, 10), Vector2(10, 11), Vector2(10, 12)]

BODY SEGMENTS:
Setiap bagian tubuh ular adalah Vector2(x, y) di dalam array.
- Elemen 0: bagian paling dekat ke kepala
- Elemen terakhir: ekor paling belakang

CARA KERJA EKOR:
1. Setiap frame, kepala bergerak
2. Bagian body ke-1 ambil posisi kepala frame sebelumnya
3. Bagian body ke-2 ambil posisi body ke-1 frame sebelumnya
4. Dan seterusnya... menciptakan efek "mengikut"

---COPY MULAI---

func _ready():
    """
    Saat game dimulai, kita setup body segments
    """
    # Buat body segments awal

func spawn_food():
    """
    Spawn makanan di posisi random
    Pastikan tidak spawn di atas badan ular
    
    Return: Vector2 - posisi food yang valid
    """
    var valid = false
    var new_pos = Vector2.ZERO  # Vector2.ZERO = Vector2(0, 0)
    
    # Loop sampai menemukan posisi yang valid
    while not valid:
        # Generate random position dalam grid
        new_pos = Vector2(
            randi() % GRID_WIDTH,
            randi() % GRID_HEIGHT
        )
        
        # Cek apakah posisi valid (tidak ada di body ular)
        # "in" operator = cek apakah element ada di array
        if new_pos not in body_segments and new_pos != snake_pos:
            valid = true  # Posisi valid, keluar loop
    
    return new_pos

---COPY SELESAI---

Penjelasan:
- while not valid: loop terus sampai valid = true
- randi() % GRID_WIDTH: random int 0 sampai GRID_WIDTH-1

WALL COLLISION:

SELF COLLISION:
Jika snake_pos ada di dalam body_segments array, ular nabrak diri sendiri.

PREVENT REVERSE:
Jika arah baru adalah 180° berlawanan arah sekarang, ignore input.
Contoh: arah sekarang RIGHT (1, 0), input LEFT (-1, 0) → 1 + (-1) = 0 → reverse!
Solusi: cek apakah direction.x + next_direction.x == 0, jika ya ignore.

func check_collision():
    """
    Cek apakah ular nabrak:
    1. Dinding (out of bounds)
    2. Badan sendiri (self collision)
    
    Jika ada, trigger game over
    """
    
    # ===== WALL COLLISION =====
    # Cek apakah posisi kepala out of grid bounds
    if snake_pos.x < 0 or snake_pos.x >= GRID_WIDTH or \
       snake_pos.y < 0 or snake_pos.y >= GRID_HEIGHT:
        game_over()
        return  # Exit function, jangan lanjut
    
    # ===== SELF COLLISION =====
    # Cek apakah posisi kepala ada di body segments
    # Loop dari index 1 (skip head), cek sisa body
    for i in range(1, body_segments.size()):
        if snake_pos == body_segments[i]:
            game_over()
            return

---COPY SELESAI---

Penjelasan:
- if snake_pos.x < 0: kepala pindah ke x negatif (kiri boundary)
- snake_pos.x >= GRID_WIDTH: kepala pindah ke x lebih besar grid (kanan boundary)
- \ di akhir baris = line continuation (lanjut ke baris berikutnya)
- range(1, body_segments.size()): loop dari index 1 (skip kepala)
- return: exit function lebih awal (tidak perlu check lebih lanjut)

- Possible fix: Cek collision logic, mungkin timing issue

============================================
STEP 3: COMMON BUGS & FIXES
============================================

BUG POTENTIAL #1: Movement terlalu cepat/lambat
FIX: Ubah MOVE_SPEED di script
- Lebih kecil = lebih cepat (contoh: 0.10)
- Lebih besar = lebih lambat (contoh: 0.20)
- Default: 0.15

BUG POTENTIAL #2: Makanan spawn di atas ular
FIX: Check spawn_food() logic
- Seharusnya ada pengecekan "not in body_segments"
- Jika masih terjadi, mungkin timing issue

BUG POTENTIAL #3: Skor tidak update
FIX: Check update_score_label()
- Pastikan function di-panggil
- Pastikan ScoreLabel node ada di scene

BUG POTENTIAL #4: Game tidak restart dengan SPACE
FIX: Check _process() input handling
- Pastikan "is_game_over and Input.is_action_pressed("ui_accept")"
- Pastikan "ui_accept" dikonfigurasi (default: SPACE)

============================================
STEP 4: OPTIMIZATION TIPS
============================================

Jika game terlalu cepat:
➜ Naikkan MOVE_SPEED (contoh: 0.20)
➜ Ini memberi waktu pemain react

Jika game terlalu lambat:
➜ Turunkan MOVE_SPEED (contoh: 0.10)

Jika merasa ada lag:
➜ Cek console untuk error
➜ Cek apakah spawn_food() loop terlalu lama
➜ (Unlikely untuk grid 20x15, tapi mungkin)

Jika visual tidak bagus:
➜ Ubah ukuran grid (GRID_SIZE = 32)
➜ Ubah ukuran canvas (GameBoard 640x480)
➜ Ubah warna di _draw()
